Question 1 · Arrays

What is printed?

A = [4, 7, 9, 2]
PRINT A[2]
A4
B7
C9
D2
Assume indexing starts at zero. Pick one answer.
Question 1 · Answer

C — 9

index:  0   1   2   3
value:  4   7   9   2

Index 2 means the third item. Do not silently start counting at one.

Question 2 · Loops

What is printed?

total = 0
FOR i = 0; i < 4; i = i + 1
    total = total + i
PRINT total
A3B4
C6D10
Question 2 · Answer

C — 6

i = 0  → total = 0
i = 1  → total = 1
i = 2  → total = 3
i = 3  → total = 6
i = 4  → stop

The condition is i < 4, so 4 is never included.

Question 3 · Operators

Assume C/Java-style ++. What is printed?

x = 5
y = x++
z = ++x
PRINT x, y, z
A5, 5, 6B7, 5, 7
C7, 6, 7D6, 5, 6
Question 3 · Answer

B — 7, 5, 7

  • x++: use 5, then increase x to 6
  • ++x: increase x to 7, then use 7
  • Final values: x=7, y=5, z=7

Trace the state after every line.

Question 4 · Stack

What does the program print?

PUSH(10)
PUSH(20)
PRINT POP()
PUSH(30)
PRINT POP()
A10, 20B20, 30
C30, 20D10, 30
Question 4 · Answer

B — 20, 30

A stack is LIFO: Last In, First Out.

top → 20   POP → 20
top → 30   POP → 30

A queue is FIFO: First In, First Out.

Question 5 · Bitwise operators

What is 5 & 3?

5 = 101
3 = 011
    ---
AND = ?
A0B1
C7D8
Question 5 · Answer

B — 1

  101
& 011
  ---
  001  = 1

AND produces 1 only where both bits are 1.

Question 6 · Recursion

What is printed?

FUNCTION f(n)
    IF n == 0: RETURN 0
    RETURN n + f(n - 1)

PRINT f(3)
A3B5
C6D9
Question 6 · Answer

C — 6

f(3) = 3 + f(2)
     = 3 + 2 + f(1)
     = 3 + 2 + 1 + f(0)
     = 6

Find the base case first. It is where recursion stops.

Question 7 · Boundaries

Which condition matches the rule?

“CGPA of 7.0 or above, and at most 1 backlog.”

OptionCondition
Acgpa > 7.0 and backlogs < 1
Bcgpa >= 7.0 and backlogs <= 1
Ccgpa > 7.0 and backlogs <= 1
Question 7 · Answer

B

“Or above” includes 7.0. “At most 1” includes 1.

7.0  → eligible
 1   → allowed

Boundaries are where hidden tests live.

Question 8 · Complexity

What is the time complexity?

FOR i = 0; i < n; i = i + 1
    FOR j = 0; j < n; j = j + 1
        compare(A[i], A[j])
AO(1)BO(log n)
CO(n)DO(n²)
Question 8 · Answer

D — O(n²)

The outer loop runs n times. Each pass runs another n-step loop.

n × n = n²

Correct on a small sample does not mean fast enough at scale.

Question 9 · AI literacy

Which prompt gives an AI coding agent the best starting point?

AWrite the code quickly.
BDo whatever is needed.
CHere are the inputs, outputs, constraints, edge cases, and test command. First explain your plan; do not edit yet.
DMake it perfect.
Question 9 · Answer

C

A strong prompt gives the agent context, a precise task, constraints, edge cases, and a verification command.

Ask for the plan before asking for code.

Question 10 · AI validation

The AI gives you code that looks correct. What next?

ASubmit immediately.
BAsk the AI if it is correct.
CInspect the diff, run tests, and test empty and boundary inputs.
DRewrite everything yourself.
Question 10 · Answer

C

Understand → Plan → Prompt → Inspect → Run → Test edges → Explain

The agent can generate code. The candidate owns correctness.

Pair challenge · 10 minutes

Write your own MCQ

  1. Choose an array, loop, stack, queue, boundary, or AI prompt.
  2. Write a short question with four options.
  3. Swap with another pair.
  4. Explain the answer using a rule.
No trick questions. The answer must be provable from the prompt.
