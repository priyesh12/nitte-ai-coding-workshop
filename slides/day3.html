Not style rules — three things

What readable actually means

  1. Names say what, not how. s → student, tmp2 → eligible
  2. One function, one job. If the name needs "and", split it.
  3. Comments say why. A comment restating the line below is noise.

Half the bugs on Day 1 were only hard to find because the code was unclear.

Clean code isn't decoration. It's bug prevention.

The loop

Write → Test → Refactor → Verify

   WRITE  -->  TEST  -->  REFACTOR WITH AI  -->  VERIFY
                              ^                     |
                              +------ commit -------+

Refactor only when tests are green.

Otherwise you cannot tell whether AI broke it, or it was already broken.

Invariant #5 — your undo button

Four git commands

git status                      # what have I changed?
git add -A && git commit -m "working: tests green"
git diff                        # what did the AI just do?
git reset --hard HEAD           # undo everything uncommitted

Commit before you prompt.

Green tests don't mean
